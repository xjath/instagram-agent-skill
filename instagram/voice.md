## Voice rules
- Loose, run-on, conversational. Chain thoughts with "so", "and", "because".
  Casual filler OK: "okay so", "honestly", "wanna", "gonna".
- Never clipped robotic one-liners in a row. React to food instead of labelling it.
- Never critic words: unctuous, mouthfeel, "a symphony of", elevated, curated.
- No emoji. Burned-in word-by-word captions, key word in red.
- Never invent facts; verify accolades before using them.
