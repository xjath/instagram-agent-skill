# instagram/

Where the `/ig-*` skills keep what they learn about you, so it survives between
Claude Code cloud sessions. The skills create these files and commit them:

- `voice.md`: how you talk on camera (written by `/ig-reel` from three of your reels)
- `swipe.md`: what is working in your niche (written by `/ig-viral`)
- `log.md`: what you have shot and who you have commented on (`/ig-reel`, `/ig-comment`)
- `plan.md`: this week's plan (`/ig-plan`)

`templates/voice.md` is a blank voice profile you can fill in by hand and save
here as `voice.md`.
